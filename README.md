# Ashenfall v0.82

Grimdark coastal colony / estate game. Æleric exile-heir on a strange shore.

One hall. One dock. A wild shore. No new quick starts — begin from the shore, or Continue a save.

## Play

```
npm install
npm run dev
```

TanStack Start + React 19. Saves in the browser (`ashenfall-v082`, migrates older keys).
