# Ashenfall v0.01

Grimdark coastal colony / estate game.

You are the heir of a deposed king, banished from the Æleric lands across the sea. You land with your household on a wild frontier and raise a hall and dock. The new land is already held by folk who share no tongue with you: goblins, orcs, elves, dwarves, and trolls.

This repository is the rules and content bible for the first build. Playable code comes later. For now, v0.01 is a complete opening loop on paper.

## Version 0.01 scope

- Single starting map: hall, dock, then sheds, then a small palisade
- Humans / Æleric only as playable people
- Day cycle and Action Points
- Starting household of six
- Exploration routes and first contacts
- Captives, watch, escape
- Captain Oswin, Renown, first settlers
- Expansion 1 lots

## Folder layout

- `docs/` — rules
- `data/` — numbers and character blocks
- `content/` — scenes and encounters

Start with `docs/00-overview.md`.
